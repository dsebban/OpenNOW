## Reusable descriptive collector

`tools/observe-stream.py` reads existing numeric Qt and native logs without
account access. It requires explicit dimensions and an exact Qt PID, checks
process identity, active presentation, refresh, timestamps, epochs, rotation
and counter continuity, and retains invalid or partial evidence. Schema 2
accepts explicit 60/100/120 Hz and records its script hash. The original
schema-1 collector used for the table is archived privately.

This helper makes no candidate-acceptance decision and does not replace or
relax the frozen `live-trial.py` scorer. It exists because the old workload was
1920×1080 at 60/120 Hz and cannot score the user's changed ultrawide/100-Hz
profile honestly. Codec, cloud session, scene and settings remain operator
assertions backed by GUI evidence.

Private evidence: `.runtime/latency-20261008/` and
`.runtime/incident-20261008/`. Raw logs, account identifiers and session material
remain excluded from Git. No performance default change has been accepted.
